# Contributing

Use focused changes and explain the behavior and validation in your pull request. Run TypeScript, lint, unit tests and the production build for app changes; run pytest and the release validator for dataset changes. Test permissions for both authorized and unauthorized roles when changing workflows.

Language contributions need provenance and an explicit redistribution license. Mark uncertain dialect information as unspecified. Do not copy third-party dictionaries without permission. Submit corrections as revisions and preserve accepted versions. Reviewers must be independent of the submission author.

Never commit credentials, service-role keys or real personal data. Governance remains provisional until founding scholars approve it. No deployment or GitHub push is part of the prototype workflow.
