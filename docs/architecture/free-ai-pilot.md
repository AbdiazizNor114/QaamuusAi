# Free AI pilot status

The integration is implemented after the owner authorized OpenRouter/model-provider transmission on 27 October 2026. Activation requires a server-only API key and a successful live test; no live provider call has been made without a key. See [setup, free-only safeguards and limitations](openrouter-setup.md).

The chat offers Free AI chat for general conversation with curated project context and Project guide for local, deterministic notes. They are clearly labelled. The guide remains usable without an API key or when the free service is unavailable. Neither is a QaamuusAI-trained speech model.
