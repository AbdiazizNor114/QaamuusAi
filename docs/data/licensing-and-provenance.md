# Licensing and provenance

Software, datasets and articles have separate licensing. MIT applies to code, not to contributed language content. Published entries and articles require their own explicit licensing review. No sample language dataset ships with the application.

Record source, contributor, reviewer, regional variation, timestamps and version. A web URL or dictionary citation is provenance, not permission. Keep uncertain rights as `Permission pending`; such entries cannot publish or export. The prototype recognizes only CC0-1.0 and CC-BY-4.0 as redistributable. Expanding the whitelist requires a licensing policy review.

Never overwrite an approved version. Corrections are independent proposals. Release manifests should eventually record the precise accepted IDs and each license/attribution requirement. No real external language resource has been imported.
